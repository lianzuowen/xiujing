# 新修嘉兴大藏经 · 交互原型

手机端 Web 原型：《新修嘉兴大藏经》认捐 / 阅藏应用。

## 文件清单

- `index822.html` — 入口页面（mobile shell）。
- `app.js` — 前端逻辑（数据 + 路由 + 视图渲染 + 事件绑定）。
- `styles.css` — 全部样式（深色 / 浅色变量、原型风）。
- `serve.js` — 本地静态文件服务器（开发时用）。

## 本地预览

```bash
node serve.js
# 浏览器打开 http://localhost:8301/
```

或用任意静态服务器：

```bash
python -m http.server 8301
```

## 主要功能

- **首页**：进度概览、近期动态、推荐经书。
- **经目**：全部 / 可认捐 / 已认捐 三视图，按部类细分 chips、按经号排序。
- **公开**：功德主中心透明账本（资金 / 进度 / 账本）。
- **我的**：功德主中心、个人中心、扫码邀请。

## 数据

- 当前样例数据：28 部经书（含《大方廣佛華嚴經》《妙法莲华经》《维摩诘所说经》《大智度论》《六祖坛经》《瑜伽师地论》等）。
- 认捐总额、用户等级、邀请关系等均在前端模拟。

## 浏览器兼容

仅在现代 mobile WebKit 中验证过。
